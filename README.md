## 📊 Power BI End-to-End Data Analytics Project

This project focuses on analyzing healthcare insurance claims, financial performance, claim approvals/rejections, fraud indicators, hospital performance, disease categories, and settlement patterns using **Power BI**


## 🎯 Project Objectives

- Analyze overall healthcare insurance claim performance.
- Monitor total claims and total claim amount.
- Analyze claim approval and rejection rates.
- Identify high-cost claims and claim amount distribution.
- Analyze claims by disease category, city, gender, and insurance plan.
- Identify suspicious and potentially fraudulent claims.
- Analyze fraud patterns across hospitals and hospital types.
- Evaluate hospital-level approval performance.
- Analyze settlement days and claim amounts.
- Build an interactive Power BI dashboard for business decision-making.

## 🛠️ Tools & Technologies

- **Power BI**
- **Power Query**
- **DAX**

# 🧹 Data Preparation
The dataset was prepared before dashboard development using data cleaning and transformation techniques.

### Data Preparation Steps

- Removed duplicate records.
- Handled missing/null values.
- Standardized categorical values.
- Corrected data types.
- Validated numerical fields.
- Checked claim amount consistency.
- Prepared date fields for time-based analysis.
- Created calculated columns where required.
- Created DAX measures for dashboard KPIs.
- Prepared data for interactive filtering.

# 📊 Dashboard 1: Claim Overview
The Claim Overview Dashboard provides a high-level view of healthcare insurance claims.
### Key KPIs
- **Total Claims:** 170.204K
- **Total Claim Amount:** 1699M
- **Approval Rate:** 71%
- **Rejection Rate:** 29%
- **Average Settlement Days:** 15.56 Days

  ### Business Insights
- The dashboard shows a higher proportion of approved claims compared with rejected claims.
- Claim amounts vary across different cities.
- Infectious and genetic disease categories contribute significantly to overall claim volume.
- Claim amounts are distributed across different gender groups.
- Average settlement time provides an indication of the claim processing cycle.
